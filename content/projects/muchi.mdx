## Overview

Muchi is a fast-paced team game built in 48 hours at the Chillennium 2024 game jam. The theme, *Hang in There*, became a game about hanging clothes against the clock to satisfy the demands of a cruel boss — frantic, funny, and a test of teamwork and time management under pressure.

## Artist-friendly hanger placement

My main feature was the hanger setup system. Artists and designers can drop new hangers into the level and choose, from an enum dropdown in the editor, which type of clothing belongs on each one.

In a 48-hour jam, every minute an artist spends waiting for a programmer is lost, so the goal was a system that was fast to use, easy to extend, and didn't need code changes for new content. It's built entirely in Blueprint.
