## Overview

Verocity is a futuristic multiplayer racing game set in a cyberpunk city of the same name — think Mario Kart with character abilities and track items. It was built by a team of ten over two years in a graduate game-production course and released on Steam.

I worked as a technical artist and tool developer. My job was the systems that sit between design and code: things artists can place, resize and forget, that still behave correctly under multiplayer replication.

## Player placement

Every racing game needs to know who's in first. My first version used straight vector maths — dot products and scalar projection against hand-placed target points. It worked, but it fought the art team: every track change meant re-placing points and matching their width to the road, and curves needed dozens of closely spaced points because the projection only works on straight segments.

After studying how shipped racing games handle ranking, I replaced it with a **cumulative distance along a spline**. It's cheaper, easier to read, and the curve problem simply disappears: artists drop a spline down the track in seconds and the system works on any map, including ones that don't exist yet.

## Minimap

The minimap converts a 3D bounding box into a 2D UI widget that shows the player and opponents with different icons. Artists adjust it by resizing the box, not by editing numbers. It can also capture the area inside the box and generate a starting texture for the map, and the widget always preserves the texture's aspect ratio so it can be scaled freely without distortion. It's C++ throughout and supports both single-player and multiplayer.

## Slope-aware movement

To make the track feel physical, player speed adapts to terrain: faster on descents, slower on climbs. A downward trace reads the surface normal; its **dot product** with the trace direction tells whether the kart is on a slope, and the **cross product** with the kart's forward vector tells whether that slope is uphill or downhill.

```cpp title="Cpp_SurfaceNormalComponent.cpp" {2,5,9-10}
FVector HitNormal = OutHit.ImpactNormal;
FVector LineTracerV = (Start - End).GetSafeNormal();
// calculation dot product to determine if the character on a slope or not!
dotProduct = FVector::DotProduct(LineTracerV, HitNormal);
if (dotProduct < .99f)
{
    // calculate the cross product to determine whether the slope is downhill or uphill
    CrossProductV = FVector::CrossProduct(LineTracerV, HitNormal);
    CharacterCross = FVector::CrossProduct(GetOwner()->GetActorForwardVector(), CrossProductV);
    if (CharacterCross.Z > 0) // character is going down
    {
        if (CharacterMovement && CharacterMovement->GetMaxSpeed() < 4999)
        {
            CharacterMovement->MaxWalkSpeed = 5000;
        }
    }
    if (CharacterCross.Z < 0) // character is going up
    {
        if (CharacterMovement && CharacterMovement->GetMaxSpeed() > 2501)
        {
            CharacterMovement->MaxWalkSpeed = 2500;
        }
    }
}
```

## Results

Verocity shipped on Steam. Afterwards I extracted the ranking and minimap systems into a standalone plugin collection — each with its own demo map for single-player and multiplayer — so artists and non-programmers can drop them into any UE5 project.
