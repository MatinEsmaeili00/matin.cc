## Overview

A transmission electron microscope is a rare and expensive instrument, and training new PhD students on it is slow and risky. LSU asked us to build a digital twin in VR so trainees can learn the instrument safely, with visual feedback that the real machine can't give: what's happening *inside* the column when they turn a knob.

I've been on the team of six since 2024 as a technical artist and tool developer, and built two systems so far.

## Electron-beam simulation

The virtual world lets us do something impossible with the real microscope — cut it in half. The simulation shows the electron beam travelling through the column and responding as trainees switch modes and adjust controls, while staying faithful to how the instrument actually behaves.

I built it in C++ from the maths up: angle-to-vector conversion to distribute rays evenly around the beam axis, a cone spread, rotation matrices about the column's axes, and reflection.

The first version was prototyped with editor debug tools and buttons so the researchers could validate the behaviour. After their feedback, I rebuilt the visual side with Niagara particle effects so it runs on Meta Quest 3 headsets.

## Labelling the instrument

The second system is a UI widget that labels each part of the microscope. It's built so artists can add and rename parts quickly without touching code — important on a model with dozens of components that the domain experts keep refining.
